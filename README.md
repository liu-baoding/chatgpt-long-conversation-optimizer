# ChatGPT Page Cleaner

一个 Tampermonkey 用户脚本，优化 ChatGPT 页面的阅读体验。

## 功能

### 1. 消息限高

独立控制助手消息和用户消息的最大高度，超出部分可滚动查看，避免长回复占用过多屏幕空间。

- 默认助手消息最大高度：`400px`
- 默认用户消息最大高度：`300px`
- 通过 Tampermonkey 菜单开关和调整

### 2. 宽表格横向滚动

为超出容器宽度的表格提供唯一横向滚动条，避免页面出现双重滚动条。

### 3. 离屏渲染休眠

利用 CSS `content-visibility: auto` 降低离屏消息的渲染开销，提升长对话性能。

- 默认占位高度：`600px`
- 可通过菜单开关和调整

### 4. 数学公式复制修复

ChatGPT 官方复制按钮会改写 KaTeX 公式内容（`\%` → `%`、间距丢失、`=` 被 Markdown 处理等），导致粘贴后公式损坏。

本脚本拦截 `navigator.clipboard.writeText/write`，将复制结果中的公式还原为标准 `$...$` / `$$...$$` 格式。

**策略：**
- **行间公式**：识别官方复制产生的独立 `[ ... ]` 块，按 DOM 顺序替换为 `$$...$$`，不依赖正文匹配
- **行内公式**：通过候选文本（原始 TeX、简化 TeX、KaTeX 可见文本）精确匹配并还原
- 保护 Markdown 代码块，避免误替换

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 新建用户脚本，粘贴 `script.js` 的全部内容
3. 保存并启用

## 配置

点击 Tampermonkey 菜单中的脚本名称，通过子菜单调整各项设置：

| 菜单项 | 说明 |
|--------|------|
| 切换助手消息限高 | 开关助手消息的高度限制 |
| 设置助手消息最大高度 | 如 `400px`、`40vh`、`25rem` |
| 切换用户消息限高 | 开关用户消息的高度限制 |
| 设置用户消息最大高度 | 如 `300px` |
| 切换离屏渲染休眠 | 开关 content-visibility 优化 |
| 设置离屏内容初始占位高度 | 如 `600px` |
| 显示当前配置 | 查看所有配置项 |

## 兼容性

- 匹配域名：`chatgpt.com`、`chat.openai.com`
- 需要浏览器支持 `content-visibility`（Chrome 85+、Edge 85+、Firefox 125+）
